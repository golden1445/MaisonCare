# MaisonCare

MaisonCare is a full-stack web application for hiring verified domestic help, designed with three main roles: Admin, Client, and Maid. The platform ensures a secure and efficient process for job posting, hiring, and verification.

---

##  Features

###  Client
- Post job requirements
- Browse and hire verified maids
- Provide ratings and reviews

###  Maid
- Create and manage profile
- Upload verification documents
- Apply for available jobs

###  Admin
- Verify maid profiles and documents
- Manage users and job listings
- Monitor platform activities

---

##  Tech Stack

- **Frontend:** React.js, HTML5, CSS3, JavaScript  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Authentication:** JWT
